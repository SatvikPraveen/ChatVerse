# Security Policy

The threat model, cryptographic design and known limitations are documented in
[docs/SECURITY.md](./docs/SECURITY.md).

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Please report vulnerabilities privately to the maintainer, Satvik Praveen, at
satvikpraveen707@gmail.com, rather than through public issues. Include a description, steps to
reproduce, and the affected component (`api`, `web`, `crypto`, `protocol`). You will receive an
acknowledgement within a few days.
